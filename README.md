# 🩺 Medical ChatBot – AI-Powered RAG-Based Q&A System

An intelligent medical chatbot built using **LangChain**, **Pinecone**, **Hugging Face**, **Groq API**, and **PDFLoader**. This project leverages **Retrieval-Augmented Generation (RAG)** to accurately answer user queries by retrieving context from custom medical documents.

---

## 🚀 Features

- 💬 Interactive medical Q&A based on uploaded PDFs
- 📄 Supports ingestion of multiple medical documents
- 🧠 RAG architecture for high-quality, grounded answers
- ⚡ Fast and semantic document retrieval via Pinecone
- 🤖 Uses Groq API for ultra-fast LLM responses
- 🔗 Fully powered by LangChain’s flexible pipeline

---

## 🛠️ Tech Stack

| Tool             | Purpose                                         |
|------------------|-------------------------------------------------|
| **LangChain**     | Handles document parsing, retrieval, and generation |
| **Pinecone**      | Stores vector embeddings for fast similarity search |
| **Groq API**      | LLM response generation                        |
| **Hugging Face**  | Embedding models for vectorization             |
| **PDFLoader**     | Loads and splits PDF documents                 |
| **(Optional)** Streamlit / Next.js | For chatbot user interface           |
